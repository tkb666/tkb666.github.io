PADS logic\layout\route 绘制4层板学习总结

概述与背景

在过去的两个多星期里，我从 Altim designer 以及 立创 eda 的两层PCB绘制的经验基础上进一步延伸学习 PADS / SAILWIND软件(SAILWIND为PADS的国产替代版本，下载与详情见链接)，并成功完成了一款四层 PCB 板的设计。在此基础上，本人将学习经验整理为以下总结，用于复习和梳理知识点，同时分享给各位正在学习的工程师们。

本次设计的四层板采用了经典的层叠结构：
Top 层（顶层走线 + 贴片）
GND 层（完整地平面）
Power 层（电源分割层）
Bottom 层（底层走线）
这种结构为信号提供了良好的回流路径，能有效降低了电磁干扰（EMI）。

接着，我将从以下几个方面对本次的绘制经理做一个总结：

软件的下载指南

PADS下载方式参考：链接。
这篇blog涵盖了下载教程和常见安装报错解决方法，小伙伴们按照该提示下载基本不会遇到问题。意外的是，本人在使用公司电脑安装PADS时，同样遇到了Script Failure报错，上述方法只解决了其中一部分问题，若遇到相同情况请检查电脑是否安装了 .NET Frame 3.5组件 (报错原因：PADS中的很多后台服务以及脚本均是基于 .NET 3.5 组件构建，安装后该报错得以解决，下载地址：链接)

PADS软件介绍与使用流程

相比于AD、立创eda的功能一体化软件，PADS由 logic、layout、route 三部分组成。其中layout和route中有铺铜、拉线等相同功能，但两个软件各有测重和独特的优势。在进行pcb的绘制时，可以同步搭配使用，这正是PADS相较于其他的EDA软件独特的特点和优势。
logic用于原理图的绘制；
layout用于元件的布局；
route则用于PCB电路的走线。

完整的PCB绘制遵循以下流程：
建库：根据物料信息建立元件的原理图CAE封装和PCB封装(通常成熟的元件库由公司提供，在遇到新原料时需要绘制并加入到库中)；
导入网表：调用库原件建立原理图，并导入到PCB文件中；
布局评审：根据要求对元器件布局，并且评估布局后的PCB的合理性；
PCB布线：布线的同时可以对元件布局进行微调，争取最优布线；
检查/修改：对PCB进行基本验证，如安全间距验证(DRC)、连接性验证、泪滴验证、结构验证等；
输出资料：Gerber文件、pdf文件、坐标文件、BOM清单。

常用的快捷键（全局），参考链接：链接
1.视图控制
Ctrl + B：适合板框（Fit to Board）
Home 或 Ctrl + D：适合所有（Fit to Drawing）
PgUp / PgDn：放大 / 缩小（以光标为中心）
Alt + Enter：打开“选项”对话框（Options）
W + 数字：设置线宽，如 W 0.2

2.设计操作
Ctrl + R：旋转对象（先选择对象）
Ctrl + E：移动对象（先选择对象）
Ctrl + F：翻转（镜像）对象到对面层
Ctrl + G：建立组合 / 取消组合（对走线、过孔等）
Ctrl + S：保存文件（PADS有时会不稳定，出现闪退等情况，建议养成即时保存的良好习惯）
F1: 打开在线帮助
F2：开始/停止走线
F3：动态走线（推荐常用）
F4：层切换（走线时）
F6：选择模式切换
F7：自动 Route
Shift + S：筛选器（Filter）对话框
Shift + Space：切换走线角度模式（45度、90度、任意角等）

3.无模命令（Modeless Commands）- PADS核心技巧
在任意时刻直接键盘输入：
G：设置设计栅格，如 G 0.1
GD：设置显示栅格，如 GD 0.05
S：搜索元件或坐标，如 S U1（定位到U1），S 100 200（定位到坐标）
SS：搜索并高亮显示对象，如 SS C1
PO：切换敷铜显示/隐藏轮廓
Q：快速测量（从一点到另一点）
R：设置显示线宽，如 R 0.5
L：切换层，如 L 2 或 L Top
Z：查看某一层，如ZZ 或 Z 1
E：切换走线结束模式（以过孔结束、以测试点结束等）
I：数据库完整性检查（快速DRC）

软件使用关键步骤与操作

1.导入网表：
这一步是原理图文件链接到PCB文件的关键步骤，发送成功并没有报错后，logic与layout可以实现交互。例如，在logic中选中模块或者元件，会在layout中高亮显示。如下图所示，勾选设计规则和对比设计规则，发送网表后，会生成一个.eer错误提示文件，核对文件中的错误信息，未找到错误即可正常进入layout中布局了。

其中，原理图连接性错误中网络名错误可以忽略。此外，在发送网表前务必保持logic与layout中有相同的元件库，在软件左上角 文件 中选择 库 进入，添加库过程如下：

添加完成后，可以按照步骤3将我们常用的库上移并置顶。

2.设计规则设置：
布线规则必须在原理图logic中设置好(这一条是公司硬性规定，通常硬件工程师会设置好，方便给其他同事直接在layout中布局)，设计规则如下所示，通常默认线宽为10mil，大功率元件需要对应铺设铜皮和加粗，在布线时，若遇到狭窄处禁止布线，可以将最小线宽改为6mil（电路原理以及工艺满足要求的前提下）。

像电源网络、电机线等网络需要单独在网络中单独设计规则。

3.走线宽度与过孔的关系：
lw×1.6>=d>=lw×1.3；
lw×2.8>=D>=lw×2；
式中，lw表示线宽，d表示过孔内径，D表示过孔外径，无论是电源还是信号，线宽和过孔遵循的规则都应该遵循上式。
不同的过孔类型可以按照以下方式进行添加：在设置中找到焊盘栈，进入后出现以下界面，按照提示依次添加所需的类型。

值得注意的是，开始、内层、结束均需要设置过孔直径和钻孔尺寸。完成上述步骤后确认，就可以在布线时使用了，当需要打过孔时，切换为所需类型的过孔即可。

4.颜色设置：
颜色设置包含两个部分，一种是相同网络的颜色，这一部分，我们通常将重要的网络，例如电源、关键信号线设置为相对鲜明的颜色，一是为了提醒我们优先布线，二是在方便在最后的内电层进行电源分割铺铜。

另一种是板层的颜色设置，网络颜色的优先级是要高于层颜色优先级的，在没有指定网络颜色时，会默认为层颜色。此外，为了保持布线时板面的整洁，我们通常将属性、参考编号选为不勾选（根据自身情况选择），同时将连线设置为黑色（隐藏飞线）。

通常一块PCB板会包含两种以上电源网络，此时使用不同颜色区分不同的电源的重要性就体现出来了，如下图所示，为内电层三种电源网络的铺铜效果：

铺铜时应优先考虑板上提供功率最大的电源，尽可能在布局时就考虑同类型电源的位置，方便大面铜皮连接。

5.布局：
布局遵循“先大后小，先难后易”的原则，重要的、核心的元件优先布局；
布局时应当参考原理图，根据主信号流向规律安排主要元器件；
连线尽可能短，关键信号线最短；
高电压、大电流信号与小电流、低电压弱信号完全分开，高频信号与低频信号分开，高频元器件的间隔要充分；
安装孔中心到边缘距离取3-5mm，相邻安装孔距离不超过150mm，面积较大的板增加安装孔（防止板变形）；
散热焊盘周边打一些过孔，并用铜箔连接起来；
芯片响铃引脚网络需要连接时，先引出在连接（直接连在一起焊接时无法判断是正常连接还是短路）。
接插件大电流引脚，为了焊接可靠，走线尽量从背面走线，若背面走不了线，则在焊盘外围打一些过孔，并在正反两面都用铜箔连接起来。如下图所示：

6.尺寸标注：
最后是尺寸标注，为了方便和机械组的工程师沟通，需要对电路板进行尺寸标注，以mm为单位，以坐标（0，0）作为基点，标注以下内容：
电路板的长和宽；
安装孔中心到0点的距离；
板厚、铜皮厚度、PCBA大概高度、安装孔内径；
需要定位的接插件或元器件到0点的水平和垂直距离，某些元器件还需要特别注明高度，等等。
