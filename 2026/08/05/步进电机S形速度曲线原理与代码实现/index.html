步进电机 7 段 S 形曲线加减速控制算法推导与C语言代码实现

前言

最近，学习并完成了步进电机驱动芯片国产替代的任务，其中有一部分要求是通过国产步进电机驱动芯片实现对电机的s形速度曲线的驱动。因此，本文围绕步进电机驱动，完成了 S 曲线的运动学推导以及 C 语言离散化实现的工程指南。以便总结和复习。

一、 基础概念

步进电机加减速控制的核心是通过调整脉冲频率实现速度平滑变化，避免启停时的机械冲击和失步。常见算法包括T型（梯形）加减速和S型加减速。相比于步进电机的 T 形曲线（T-Curve），S 形曲线（S-Curve）减少了由于加速度突变带来的冲击（Jerk）和系统振荡。

此外 S 形曲线并没有具体的限定的和轨迹，可以是正弦函数、指数函数，也可以是自定义函数。只要满足速度曲线是一个“S”即可。常用的 S 形曲线有Sigmoid函数、5 段、7 段 S 形速度曲线。Sigmoid有显式的函数解析式，速度的计算与理论公式的推导更简单，本文主要讲解7段 S 形速度曲线的推导。

7 段速度曲线分别对应为：
$OA$: 加加速段 、$AB$: 匀加速段、 $BC$: 减加速段、 $CD$: 匀速段 、$DE$: 加减速段、 $EF$: 匀减速段、 $FG$: 减减速段。其中 7 段 S 形速度曲线比 5 段在加速段和减速段中分别多出了匀加速段和匀减速段。

[!CAUTION]
当设置的最大速度$v_{max}$、最大加速度 $a_{max}$、加加速度 $j$ 以及总步数 $\Delta S$ 不匹配时，7 段 S 曲线会退化成 6 段、5 段甚至 4 段。因此，在编写代码时，不能理想的认为我们设置的初始条件能够完全满足7段中的每一段曲线的实现，应该考虑到不满足时，速度曲线应当是一种怎样的形态。即使是4段，速度曲线也依然是S形，只是可能没有了匀速段、匀加速段或者匀减速段。

二、 基础变量定义

[!TIP]
S 曲线运动核心积分公式化简：
$$a(t) = a_0 + j \cdot t$$
$$v(t) = v_0 + a_0 \cdot t + \frac{1}{2} j \cdot t^2$$
$$S(t) = S_0 + v_0 \cdot t + \frac{1}{2} a_0 \cdot t^2 + \frac{1}{6} j \cdot t^3$$

无论是在理论推导、公式计算还是实际的工程开发中。我们都需要在系统开始前明确已知量，在实际的步进电机驱动控制开发中，我们会设定总的步进步数 $S_{total}$、最大速度 $v_{max}$、最大加速度 $a_{max}$ 以及加加速度 $j$ 作为已知量。接着我们将这些已知量代入 S 形曲线算法中，计算出每一步所对应的实时速度 $V_{real}$。进而转换为定时器的计数值。

输入：

  • $v_0$: 初始速度（通常设为 0）
  • $v_{end}$: 最终停止速度（通常设为 0）
  • $v_{max}$: 设定的目标最大运行速度
  • $a_{max}$: 设定的最大加速度（假设加减速对称 $a_a = a_d = a_{max}$）
  • $j$: 加加速度 / 冲击（假设加减速段加加速度大小相等 $j_a = j_d = j$）
  • $S_{total}$：设定的目标位移量

输出：

  • $T_i$: 第 $i$ 段的运行时间
  • $\Delta S_i$: 第 $i$ 段的运行步数（位移）
  • $V_{real}$: 每一步所对应的速度，即每一个pwm脉冲对应的频率

接着，我们进行理论的推导。在理想情况下，我们默认每一段曲线（7 段）都能完整实现，也就是我们的总步长足够长，有足够步数和时间让速度可以加速到最大值。

二、 7 段位移与速度推导过程

[!TIP]
以下各公式的推导均是来源于基本积分公式的计算，可以结合各阶段曲线图像的面积来理解。

1. 加加速段 ( Acceleration Build-up )

加速度从 0 线性增加到 $a_{max}$。

  • 状态：$a_0 = 0, j = j$
  • 时间：$T_1 = \frac{a_{max}}{j}$
  • 末端速度：$v_1 = v_0 + \frac{1}{2} j T_1^2$
  • 本段步数：$\Delta S_1 = v_0 T_1 + \frac{1}{6} j T_1^3$

2. 匀加速段 ( Constant Acceleration )

加速度保持为最大值 $a_{max}$，速度线性增加。

  • 状态：$a = a_{max}, j = 0$
  • 末端速度：$v_2 = v_1 + a_{max} T_2$
  • 本段步数：$\Delta S_2 = v_1 T_2 + \frac{1}{2} a_{max} T_2^2$

3. 减加速段 ( Acceleration Reduction )

加速度从 $a_{max}$ 线性减小到 0。虽然 $j$ 为负，但加速度 $a(t) \ge 0$，因此速度依然在正向增加。

  • 状态：$a_0 = a_{max}, j = -j$
  • 时间：$T_3 = T_1 = \frac{a_{max}}{j}$
  • 末端速度：$v_3 = v_2 + a_{max} T_3 - \frac{1}{2} j T_3^2$
  • 本段步数：$\Delta S_3 = v_2 T_3 + \frac{1}{2} a_{max} T_3^2 - \frac{1}{6} j T_3^3$

4. 匀速段 (Constant Velocity)

加速度为 0，以最大速度 $v_{max}$ 匀速运行。

  • 状态：$a = 0, j = 0$
  • 本段步数：$\Delta S_4 = v_{max} T_4$

5. 加减速段 (Deceleration Build-up)

  • 状态：$a_0 = 0, j = -j$
  • 时间：$T_5 = \frac{a_{max}}{j}$
  • 本段步数：$\Delta S_5 = v_{max} T_5 - \frac{1}{6} j T_5^3$

6. 匀减速段 (Constant Deceleration)

  • 状态：$a = -a_{max}, j = 0$
  • 本段步数：$\Delta S_6 = v_5 T_6 - \frac{1}{2} a_{max} T_6^2$

7. 减减速段 (Deceleration Reduction)

  • 状态：$a_0 = -a_{max}, j = j$
  • 时间：$T_7 = T_5 = \frac{a_{max}}{j}$
  • 本段步数：$\Delta S_7 = v_6 T_7 - \frac{1}{2} a_{max} T_7^2 + \frac{1}{6} j T_7^3$

[!CAUTION]
到这里我们完成了每一段的速度和步数推导，接着我们回到最初的问题：什么时候7段曲线会退化为 6、5、4 段曲线？

三、 短路程下S形速度曲线的重新推导

[!NOTE]

  • 6 段曲线：无匀速段，速度刚好达到最大值就得马上进入减速段。
  • 5 段曲线：无匀加速段，$v_{max}$太低，跑不到加速度上限，但位移又足够跑出匀速段。
  • 4 段曲线：既无匀速段、也无匀加速段。$v_{max}$太低，位移又不足够跑出匀速段。


此时，不能继续使用上文中 7 段完整 S 曲线的推导公式。对于四种不同情况的速度曲线，无非就是有无匀加速和匀速阶段。它们都受限于能否达到最大速度（决定有无匀速）、最大加速度（决定有无匀加速）、以及实际位移与理想位移的比较。对此，我们引入三个临界阈值来区分以上四种不同情况：

[!TIP]
以下公式的推导大家可以根据图像的面积和曲线的对称性来理解。其中临界位移需要综合考虑$V_{max}$是否能够达到$v_{limit}$。

  1. 临界速度：$v_{limit} = \frac{a_{max}^2}{j}$ （达到 $a_{max}$ 时的最小速度增量）
  2. 临界 $a_{max}$ 位移：$S_{amax} = \frac{2 \cdot a_{max}^3}{j^2}$ （理想状态下，达到$a_{max}$时加减速段的最小位移）
  3. 临界 $V_{max}$ 位移:
    $$ S_{vmax} = 2V_{max}\sqrt{\frac{V_{max} }{j}} $$ (达不到$a_{max}$时，要实现$V_{max}$加减速段的最小位移)；
    $$ S_{vmax} = V_{max}(V_{max}/{a_{max}} + a_{max}/{j}) $$ (达到$a_{max}$时，要实现$V_{max}$加减速段的最小位移）

以下是判断四种情况的决策树：

情况 C：4段曲线（无匀加速段、无匀速段）

  • 最大速度不满足及速度跑完；（注定没有匀加速段）
  • 位移不满足加速度跑完；（注定没有匀加速段）
  • 唯一不支持最大速度跑完。（注定没有匀速段）

那么4段曲线的每一阶段的输出推导如下：
OA段末状态：
$$
a_{OA}=JT_1
$$
$$
V_{A}=\int_{0}^{T_1} Jt , dt=\frac{1 }{2}JT_1^2
$$
AB段末状态：
$$
V_{B}=V_{A}+\int_{T_1}^{T_2} JT_1-J(t-T_1) , dt=JT_1^2
$$
根据对称性，可得
$$
S_{total}=V_{B}*2T_1=2JT_1^3
$$

[!TIP]
5段、6段计算推导参考4段的推导，这里不展开了。

情况 B：5段曲线（无匀加速段）

  • 最大速度不能满足加速度跑完（注定没有匀加速段）；
  • 位移满足最大速度跑完。

情况 A：6段曲线（无匀速段）

  • 最大速度能满足加速度跑完；
  • 位移满足加速度跑完；
  • 位移不满足最大速度跑完。（注定没有匀速段）
